# Claude Code Project Rules

Before making frontend changes in this repository, read:

- `../.rules/frontend-product.rules.md`

## Mandatory Behavior

- Treat this app as a civic research explorer, not a generic dashboard.
- Do not weaken the story-first Overview page.
- Do not remove or hide multilingual context.
- Do not add unsourced event annotations.
- Keep the Topic Atlas, Timeline, and Speech Explorer aligned with the product rules.

If there is a conflict between implementation convenience and the rules file, follow the rules file.
